# Security policy

## Supported versions

Security fixes are provided for the latest published Model Peek release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the
repository's **Security** tab to open a private security advisory. Include the
affected version, reproduction steps, and the practical impact when possible.

Model Peek intentionally has no network functionality. Security reports about
STL parsing, unexpected file writes, unsafe installation behavior, or release
artifact integrity are still welcome.
