# Model Peek privacy statement

Model Peek is designed to work entirely on the local computer.

- It has no telemetry, analytics, advertising, account system, cloud service,
  automatic updater, or network feature.
- It reads only an STL file that the user opens, drops onto the window, or
  passes on the command line.
- It does not edit, overwrite, repair, rescale, upload, or otherwise modify STL
  files.
- It does not keep a recent-files list or write model names to an application
  log.
- Model geometry and filenames remain in local process memory while the app is
  running. The self-contained .NET runtime may use operating-system-managed
  temporary files for its own bundled native components.

This statement describes Model Peek itself. GitHub's website and download
service have their own privacy practices when someone visits the repository or
downloads a release.
